# Figma Make Configuration

This directory contains the configuration and supporting files used by Figma
Make and Code Layers to install dependencies, run the development server, build
previews, and publish this project.

## Keeping this directory in version control

Keep the `figma/` directory in the repository. When the project is imported
again, Figma Make can reuse these files to restore its workflow and start a
preview without requiring a manual setup from scratch.

## Learn more

For details on working with Git in Figma Make and Code Layers, see the
[Figma Help Center guide](https://help.figma.com/hc/en-us/articles/44220165255063-Use-Git-with-Figma-Make-and-code-layers#h_01M5X47F86RN1RW0F8565KZHB8).
